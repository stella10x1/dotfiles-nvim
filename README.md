# Dotfiles Neovim

This are my [Neovim](https://neovim.io/) dotfiles utilizing
[NvChad](https://github.com/NvChad/NvChad).


# Installation

    git clone https://codeberg.org/lingling/dotfiles-nvim ~/.config/nvim
